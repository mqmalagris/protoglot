# protoglot (npm)

Installs the [`protoglot`](https://github.com/mqmalagris/protoglot) CLI — a
local-first, git-friendly multiprotocol API client (REST / GraphQL / SOAP /
WebSocket / gRPC) with a CI-first command line.

```sh
npm i -g protoglot
protoglot --help     # also available as `pglot`
```

On install, the matching prebuilt binary for your platform is downloaded from
the project's GitHub release (Linux / macOS x64+arm64 / Windows x64). For other
platforms, install via `cargo install protoglot-cli` or build from source.

Docs & source: <https://github.com/mqmalagris/protoglot>
